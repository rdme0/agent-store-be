# Spring Phase 5 — x402 Bridge failure matrix

이 slice는 `HIGH_RISK`다. Spring은 durable payment attempt와 budget reservation을 commit한 뒤 HMAC으로 인증된 Node bridge에만 위임한다.
private key와 signed payment payload는 Node bridge 메모리 밖으로 나가지 않는다.
