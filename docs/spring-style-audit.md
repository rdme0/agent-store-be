## 감사 결론

- 모든 persistence entity가 `common.model.entity.BaseEntity`를 상속한다.
- Java는 entity/VO/enum, Kotlin은 controller/service/repository/DTO/client/resolver/runner/orchestrator/event 경계를 따른다.
- `@ManyToOne` 자체는 finding이 아니다. 현재 scalar UUID FK는 quote snapshot, runtime call path, cross-process boundary를 보존하기 위해
  유지한다.
- cross-domain Repository 우회는 Service 경계로 제거했고, role package 및 파일 단위 책임도 기준 스타일에 맞췄다.
