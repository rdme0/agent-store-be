# Spring Phase 5 — Agent endpoint SSRF policy failure matrix

Risk: `HIGH_RISK`. An Agent endpoint is a persisted external-side-effect destination. The endpoint
is checked at write,
activation, quote snapshot, and immediately before the existing payment client sends the request. A
later DNS rebinding
therefore fails closed at invocation time rather than relying on the earlier validation.

| Boundary                   | Failure or attack                                                                                       | Durable result                                                                     | Retry/idempotency                                                                                 | User-visible outcome                      | Test                                                                                                                                                 |
|----------------------------|---------------------------------------------------------------------------------------------------------|------------------------------------------------------------------------------------|---------------------------------------------------------------------------------------------------|-------------------------------------------|------------------------------------------------------------------------------------------------------------------------------------------------------|
| registration/version draft | malformed URL, credential URL, non-HTTP(S) URL                                                          | no AgentVersion is saved                                                           | client may correct and retry                                                                      | `INVALID_ENDPOINT`                        | `AgentEndpointPolicyTest.production fails closed when DNS resolution fails or endpoint is malformed`                                                 |
| publish                    | draft endpoint is no longer permitted by active profile                                                 | version remains `DRAFT`                                                            | publish may retry after valid endpoint is supplied in a new draft                                 | `UNSAFE_AGENT_ENDPOINT`                   | policy unit tests                                                                                                                                    |
| quote                      | a resolved root or dependency endpoint is unsafe                                                        | no quote snapshot is saved                                                         | quote may retry after valid active versions exist                                                 | `UNSAFE_AGENT_ENDPOINT`                   | policy unit tests; quote traversal uses every resolved node                                                                                          |
| payment invocation         | DNS rebinding or endpoint change in an old quote                                                        | no outbound HTTP request is made unless the request uses the just-validated IP set | normal execution failure/recovery flow handles the failed invocation; no new side effect occurred | `UNSAFE_AGENT_ENDPOINT` / payment failure | policy and client admission tests; `PinnedAgentDnsResolver` binds Apache HttpClient to the validated addresses while retaining the original Host/SNI |
| redirect                   | an allowed endpoint responds with a redirect to an internal target                                      | redirect is not followed and no second-hop request exists                          | client receives a failed invocation                                                               | payment failure                           | Apache redirect handling is disabled and `SimulatedPaymentClient` rejects 3xx responses                                                              |
| development                | external or alternate loopback spelling                                                                 | no request is sent                                                                 | no DNS lookup is trusted                                                                          | `UNSAFE_AGENT_ENDPOINT`                   | `development accepts only explicit loopback hosts`                                                                                                   |
| production DNS             | resolution failure, private, link-local, loopback, multicast, unspecified, reserved, or mixed addresses | no request is sent                                                                 | retry only after all addresses are public                                                         | `UNSAFE_AGENT_ENDPOINT`                   | production policy tests                                                                                                                              |

The native x402 client resolves through `AgentEndpointPolicy` immediately before its outbound Agent
invocation and uses
the resulting pinned client for both the unpaid and paid request. The policy intentionally allows
only `localhost`, `127.0.0.1`, and `[::1]` in
`dev`, `development`, and `test` profiles; every other profile requires HTTPS plus an all-public DNS
result.
