# Spring Phase 4A — PostgreSQL simulated runtime failure matrix

Risk: `HIGH_RISK`. Spring `bootRun` constructs a PostgreSQL `DataSource` directly from
standard `SPRING_DATASOURCE_*` properties; Flyway validation
and migration remain fail-closed. PostgreSQL integration tests remain explicitly opt-in through
`RUN_POSTGRES_INTEGRATION_TESTS=true` and `SPRING_EXCLUSIVE_MAINTENANCE=true`, while default Gradle
unit tests do not
create a PostgreSQL connection.

## Maintenance test command

```powershell
# PostgreSQL integration tests only; normal Spring startup does not require either flag.
$env:RUN_POSTGRES_INTEGRATION_TESTS = 'true'
$env:SPRING_EXCLUSIVE_MAINTENANCE = 'true'
./gradlew.bat test --tests '*Postgres*IntegrationTest'
```

No test may truncate a table or issue a broad `DELETE`. `PostgresFixtureCleaner` tracks every
supported AgentStore FK
record type and deletes only registered UUIDs in reverse dependency order.
